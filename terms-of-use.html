4. Squad sharing

When you start tracking with a squad code, the app sends your position, depth, trail, battery level, chosen name and pins to other phones using the same code within radio range, and those phones relay them. You control this by choosing the code and starting or stopping tracking. Do not share a code with people you do not want to see your position. We do not operate any server and never receive this data.
